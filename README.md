PromptPilot is a Python-based interface to Meta’s LLaMA2-70B-chat model hosted on AWS Bedrock. This project demonstrates how to send prompts to a large language model via the Bedrock API and receive intelligent, real-time responses — ideal for building educational tools, chat assistants, and AI-driven applications.

In this example, the model is asked to explain the difference between supervised and unsupervised learning with real-world examples. You can easily customize the prompt to suit any use case.
